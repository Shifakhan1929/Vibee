# Vibee 🎉

A modern UI/UX redesign of the Vibe platform, focused on creating a visually engaging, intuitive, and responsive user experience.

The project explores improved layouts, visual consistency, typography, navigation, and overall interface design while preserving the platform's existing functionality.

##  Highlights

- Modern and refined user interface.
- Improved visual hierarchy and typography.
- Responsive layouts for different screen sizes.
- Enhanced navigation and user experience.
- Consistent color palette and design elements.
- UI improvements while retaining existing functionality.

##  Project Goals

- Improve the overall look and feel of the platform.
- Create a smoother and more intuitive user journey.
- Build a consistent design across different pages.
- Make the interface visually appealing and user-friendly.

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/Shifakhan1929/Vibee.git
cd Vibee
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
